## Project Overview: Minimalist Splitwise on Cardano
The goal is to build a simplified version of Splitwise. The app allows users to create groups, invite members, and manage a list of shared expenses that automatically calculates the total and splits the cost.
### Tech Stack
 * *Frontend:* React
 * *Backend:* Python
 * *API:* Blockfrost
 * *Blockchain:* Cardano (using necessary SDKs)
### Team Assignments
 * *Frontend (Aaron & Lovely):* Implement the UI/UX design and the look of the frontend.
 * *Backend (Christian):* Implement the wallet connection.
 * *Backend (Zendy):* Implement basic wallet transactions.
 * *Backend (Me):* Technical support and overall integration.
### Core Features
 * Create groups and invite people.
 * Group members can add, remove, or delete items from a list.
 * Automatically output the total and split the costs among members.
